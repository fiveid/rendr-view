# @rendr-view/component

The boilerplate template for creating new `rendr-view` packages.

## 1. Metadata

- **Package Name:** `@rendr-view/component` (Template)
- **Description:** A standardized starting point for new components/packages.
- **Category:** UI Primitive

## 2. API Design

### Exports

- `Component` (Default): A placeholder component.

## 3. Implementation Details

- **Standard Setup:** Pre-configured with Vite, Vitest, and ESLint 9 support via workspace-level inheritance.

## 4. Usage Example

```tsx
import Component from "@rendr-view/component";

return <Component />;
```

## 5. Usage as Template

1. Copy `packages/_boilerplate` to `packages/my-new-package`.
2. Rename `package.json` name to `@rendr-view/my-new-package`.
3. Start implementing in `src/`.
